# Security Policy

## Supported Versions

This superseded repository has no supported versions. Use [`sas-ci360-sdk`](https://github.com/mnelson3/sas-ci360-sdk) for the maintained implementation.

## Reporting a Vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private vulnerability-reporting feature when available, or email `support@nelsongrey.com` with the subject prefix `[Security]`.
